## Accounts

```bash
pointed accounts list
pointed accounts get <accountId>
pointed accounts create --name "Acme" --domain acme.example --revenue 120000 --renewal-date 2027-03-31
pointed accounts update <accountId> --industry Logistics --field "Open opportunities=2"
pointed accounts update <accountId> --clear renewal-date --remove-field "Open opportunities"
pointed accounts update <accountId> --context-file account-briefing.txt
pointed accounts context <accountId>
pointed accounts import customers.csv --dry-run
pointed accounts import customers.csv --enroll <templateId>
```

`--revenue` and `--contract-value` accept finite, nonnegative numbers without currency symbols or thousands separators. Use `120000`, not `120,000`. Both aliases work on create and update. Dates use `YYYY-MM-DD`.

Create accepts `--name`, `--domain`, `--industry`, `--revenue` / `--contract-value`, `--renewal-date`, repeated `--field "Label=Value"`, `--notes`, and either `--context` or `--context-file`. Update accepts those fields plus `--website`, repeated `--remove-field`, and `--clear revenue,renewal-date`. Fixed respondent-domain rules still apply to account updates.

Context replaces the saved account briefing. If the account write succeeds but its context fails, the command prints the saved account with `contextError` and exits with status 1. Retry the context with `accounts update <accountId>` instead of creating another account.

See [Account imports and context](/docs/account-imports) for spreadsheet matching, limits and partial-result handling.

## Contacts

```bash
pointed contacts list --account-id <accountId>
pointed contacts create --account-id <accountId> --name "Jane Doe" --email jane@acme.example --phone "+1 415 555 0134"
pointed contacts update <contactId> --phone "+1 212 555 0100"
pointed contacts update <contactId> --phone ""
pointed contacts delete <contactId>
```

Batch create contacts from JSON:

```bash
pointed contacts create-batch --account-id <accountId> --input-file contacts.json
```

`contacts.json`:

```json
[
  {
    "name": "Jane Doe",
    "email": "jane@example.com",
    "title": "VP Product",
    "phone": "+1 415 555 0134"
  }
]
```

Phone numbers accept 7–15 digits with common separators. An empty `--phone ""` clears the saved number.

Batch creation prints the complete result as JSON and exits with status 1 if any row fails. Existing contacts are reported separately and do not count as failed rows. Contact department fields are not supported; use `--title` for a job title.

## Campaigns

```bash
pointed campaigns list --account-id <accountId>
pointed campaigns get <campaignId>
pointed campaigns create \
  --account-id <accountId> \
  --name "Renewal proof" \
  --context "Customer story collection for renewal" \
  --initial-question "What outcome did this work unlock?"
pointed campaigns update <campaignId> --name "Updated title" --max-rounds 5
```

`--max-rounds` requires a positive integer for campaigns and story templates.

## Links

```bash
pointed links generate --campaign-id <campaignId>
pointed links generate --campaign-id <campaignId> --contact-ids id1,id2
pointed links generate --campaign-id <campaignId> --contact-emails jane@example.com,john@example.com
```

Omitting both contact selectors includes all account contacts. An explicitly empty selector is rejected, including an empty shell variable. Link generation prints all results and exits with status 1 if any selected contact fails.

## ElevenLabs interview settings

Configure reusable Demo Mode links or interview templates without starting a call:

```bash
pointed interviews settings list --kind demo
pointed interviews settings list --kind story_template
pointed interviews settings get <targetId> --kind demo > interview-settings.json
pointed interviews settings provider --kind demo --id <targetId> --channel browser_audio
pointed interviews settings set <targetId> --kind demo --file interview-settings.json
```

`settings get` exports `expectedRevision`, `openingQuestion`, `context`, `instructions`, and `elevenLabsSettingsJson`. Advanced JSON uses native ElevenLabs `conversation_config` names. `{}` uses Pointed's standard connection defaults; inspect effective model, voice, turn and other tuning values with `settings provider` before changing them. Use `--channel phone` for phone defaults. Web voice and web video share the `browser_audio` provider settings. Provider credentials, tools, consent and security remain managed by Pointed.

With the 0.5.0 source CLI, template settings files also include `interviewChannel`. Use `browser` for a web interview with an optional camera, `browser_video` to require camera consent, or `browser_audio` for voice only. Choose `phone` for phone only or `participant_choice` to offer phone and web with an optional camera. A saved `null` preserves the older phone and web voice choices.

Keep `expectedRevision` while editing. A conflict exits with status 1, prints the current revision as JSON, and leaves your file intact. Read the latest settings and reconcile your edits before another save. The CLI does not automatically retry conflicting writes. List results are paginated; continue with `--cursor` until `nextCursor` is null. `--limit` accepts 1–25.

Saving requires a user-backed workspace writer with `pointed:write`. It may provision an isolated provider configuration, but does not send invitations or start calls or recordings. Settings affect future runs; existing invitations retain their frozen configuration.

### Founder voice settings

Platform administrators can inspect founder demos and configure their browser voice or phone channels after `pointed auth login --admin`:

```bash
pointed admin demos list
pointed admin demos get <definitionId>
pointed admin demos voice-settings get <definitionId> --channel phone > phone-settings.json
pointed admin demos voice-settings set <definitionId> --file phone-settings.json
```

Use `--channel browser_audio` for browser voice. The editable envelope contains `channel`, `expectedRevision`, and `configuration`, including `elevenLabsSettingsJson`. Blank connection identifiers resolve to the standard Pointed connection on the server. The server rechecks current platform-admin authority before committing a save. These commands configure voice channels independently of the founder text-interview engine and do not initiate a call.


### Control future contacts during enrollment

In the upcoming 0.5.0 source version, `story-templates enroll` accepts `--auto-include-new-contacts` and `--no-auto-include-new-contacts`. Omitting both inherits the template default for new account enrollments and preserves existing account choices. See [Interview templates](/docs/story-templates#manage-enrollment) for template-wide and per-account behavior.
