---
title: Campaigns
description: Find an account's interviews, create interview links with your own reference, and export interview responses.
---

A campaign is the set of interviews for one account. Its contacts share one brief: a title, context for the interviewer and an opening question. Each contact gets their own interview link.

A campaign is created in one of two ways:

- You enroll an account in a story template. Pointed creates the account's campaign from the template. See [Enroll accounts](/docs/api/story-templates#enroll-accounts).
- You create one directly with [Create a campaign](#create-a-campaign).

## The campaign object

```json
{
  "_id": "kh7b3q5n8v2c6x1z4m9l0p7s3d",
  "_creationTime": 1795183500000,
  "orgId": "kd7w2m4x8q1v6n3s9t5y0z2b7c",
  "accountId": "j57a1m6c3x9z2q8w4e7r5t0y1u",
  "storyTemplateId": "ks91t4w7y2z5b8d3g6j0m1n4pq",
  "title": "Customer stories",
  "context": "Capture the before-and-after story behind the results Acme has seen.",
  "initialQuestion": "What changed after you adopted the product?",
  "maxRounds": 4,
  "status": "active",
  "createdBy": "kn83p5r2u7h4b1d6g9j0m3c8fa",
  "createdAt": 1795183500000
}
```

| Field | Type | Description |
| --- | --- | --- |
| `_id` | string | The campaign ID. |
| `_creationTime` | number | When the record was stored, in milliseconds. |
| `orgId` | string | Your workspace ID. |
| `accountId` | string | The account the campaign belongs to. |
| `storyTemplateId` | string | The story template the campaign came from. Left out for a campaign created directly. |
| `title` | string | The title. |
| `description` | string | A description. Left out when not set. |
| `context` | string | Background for the interviewer. |
| `initialQuestion` | string | The opening question. |
| `maxRounds` | number | The number of interview rounds: the opening question plus the follow-ups. |
| `status` | string | `draft` for a campaign created with this API. `active` for a campaign created by enrolling an account in a story template. Other values exist, such as `completed`. |
| `createdBy` | string | The Pointed user who created it. |
| `createdAt` | number | When the campaign was created, in milliseconds. |

A campaign can carry other fields that this reference does not list.

## Create a campaign

```text
POST /api/cli/v1/campaigns
```

**Authorization:** scopes `pointed:read` and `pointed:write`. A user-backed credential with the admin or member role.

Creates a campaign with status `draft`. Creating a campaign does not create links, send email or start an interview.

**Body parameters**

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `accountId` | string | Yes | The account the campaign is for. |
| `title` | string | Yes | The title. |
| `context` | string | Yes | Background for the interviewer: what you want to learn. |
| `initialQuestion` | string | Yes | The opening question. |
| `description` | string | No | A description. |
| `maxRounds` | number | No | The number of interview rounds. The default is 4. |

**Response:** `201 Created`. `data` is the new [campaign object](#the-campaign-object).

```json
{
  "data": {
    "_id": "kh7b3q5n8v2c6x1z4m9l0p7s3d",
    "_creationTime": 1795183500000,
    "orgId": "kd7w2m4x8q1v6n3s9t5y0z2b7c",
    "accountId": "j57a1m6c3x9z2q8w4e7r5t0y1u",
    "title": "Customer stories",
    "context": "Capture the before-and-after story behind the results Acme has seen.",
    "initialQuestion": "What changed after you adopted the product?",
    "maxRounds": 4,
    "status": "draft",
    "createdBy": "kn83p5r2u7h4b1d6g9j0m3c8fa",
    "createdAt": 1795183500000
  },
  "meta": {
    "requestId": "3f6c1e0a-8b7d-4c2e-9a41-5d0e7b9c2f18"
  }
}
```

**Errors**

| Status | When |
| --- | --- |
| 400 | `accountId`, `title`, `context` or `initialQuestion` is missing or is not a string. |
| 403 | The credential may not write. See [authentication errors](/docs/api/authentication#authentication-errors). |
| 500 | The body is not valid JSON, the account was not found, or `description` or `maxRounds` has the wrong type. |

**Example**

```bash
curl -X POST https://app.usepointed.ai/api/cli/v1/campaigns \
  -H "Authorization: Bearer $POINTED_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "accountId": "j57a1m6c3x9z2q8w4e7r5t0y1u",
    "title": "Customer stories",
    "context": "Capture the before-and-after story behind the results Acme has seen.",
    "initialQuestion": "What changed after you adopted the product?"
  }'
```

## Create interview links

```text
POST /api/cli/v1/campaigns/{id}/links
```

**Authorization:** scopes `pointed:read` and `pointed:write`. A user-backed credential with the admin or member role.

Creates one interview link for each selected contact on the campaign's account. A link is personal to its contact. Creating a link does not send email.

**Path parameters**

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | string | Yes | The campaign ID. |

**Body parameters**

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `contactIds` | array of strings | No | The contacts to create links for, by ID. 1 to 100 entries. |
| `contactEmails` | array of strings | No | The contacts to create links for, by email. 1 to 100 entries. Case is ignored. |
| `reference` | string | No | Your own label for every link in this request, such as a user ID or an order number. Up to 200 characters, with no line breaks or control characters. |

Send `contactIds` or `contactEmails`, not both. Send neither to create links for every contact on the account. The route needs a JSON body in every case, so send `{}` when you select no one.

How links behave:

- A new link is valid for 30 days.
- If the contact already has a valid link for this campaign, Pointed returns that link with `"reused": true` and creates nothing.
- `reference` comes back in webhook events as `invite.reference`. See [Your own IDs](/docs/webhooks#your-own-ids).
- When a link is reused, a `reference` in the request replaces the stored one until the interview starts. After the interview starts, the stored reference stays. A request without `reference` leaves the stored one as it is.

**Response:** `200 OK`. The status is 200 even when some contacts fail.

```json
{
  "data": {
    "requested": 1,
    "succeeded": 1,
    "failed": 0,
    "results": [
      {
        "index": 0,
        "contactId": "k17c9p4e2r8u5h3b6d1g0j7m9n",
        "status": "success",
        "contactName": "Sarah Lee",
        "contactEmail": "sarah@acme.com",
        "accountName": "Acme",
        "token": "Qm3xV8nT2kLp9RzW5yBd7HcJ4sFg6AeU",
        "inviteId": "jd7f2k9x0m4q8v1n3s6t5w2y7z",
        "reference": "user_8231",
        "reused": false,
        "surveyUrl": "https://app.usepointed.ai/survey/acme/Qm3xV8nT2kLp9RzW5yBd7HcJ4sFg6AeU"
      }
    ]
  },
  "meta": {
    "requestId": "3f6c1e0a-8b7d-4c2e-9a41-5d0e7b9c2f18"
  }
}
```

A contact that fails has an entry like this in `results`, and counts toward `failed`:

```json
{
  "index": 1,
  "contactId": "k84m1t6x3b9q2w7e5r0y8u4i6o",
  "status": "error",
  "error": "contact not found on this account or not authorized"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `requested` | number | How many contacts were selected. |
| `succeeded`, `failed` | number | How many links were returned and how many contacts failed. |
| `results[].index` | number | The position of the contact in your `contactIds` or `contactEmails` array, from 0. |
| `results[].status` | string | `success` or `error`. |
| `results[].contactId` | string | The contact ID. An empty string when an email did not match a contact. |
| `results[].contactName`, `results[].contactEmail`, `results[].accountName` | string | The person and account the link was issued to. |
| `results[].surveyUrl` | string | The link to give to the contact. |
| `results[].token` | string | The secret part of the link. |
| `results[].inviteId` | string | The ID of this interview. It is `data.interview.id` in webhook events and the ID the [invite routes](/docs/api/invites) take. |
| `results[].reference` | string or null | The reference now stored on the link. |
| `results[].reused` | boolean | `true` if the link already existed. |
| `results[].error` | string | The reason. Present for `error`. |

**Errors**

| Status | `meta.code` | When |
| --- | --- | --- |
| 400 | none | `reference` is not a string, both `contactIds` and `contactEmails` were sent, or the one you sent is not an array, is empty or holds more than 100 entries. |
| 400 | `INVALID_REQUEST` | `reference` is too long or contains a line break or control character. |
| 403 | none | The credential may not write. See [authentication errors](/docs/api/authentication#authentication-errors). |
| 404 | none | You sent `contactIds` or `contactEmails` and the campaign was not found. |
| 409 | `INTERVIEW_CHANNEL_UNAVAILABLE` | The interview has no voice channel set up. No link is created for anyone in the request. Set up browser or phone interviews in Pointed first. |
| 500 | none | The body is missing or is not valid JSON, the campaign was not found and you selected no contacts, or the account has no contacts. |

**Example**

```bash
curl -X POST https://app.usepointed.ai/api/cli/v1/campaigns/kh7b3q5n8v2c6x1z4m9l0p7s3d/links \
  -H "Authorization: Bearer $POINTED_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"contactIds": ["k17c9p4e2r8u5h3b6d1g0j7m9n"], "reference": "user_8231"}'
```

## Export a campaign's responses

```text
GET /api/cli/v1/campaigns/{id}/export
```

**Authorization:** scopes `pointed:read` and `pointed:evidence`. Any credential.

Returns the campaign's responses as [bundles](#the-response-bundle), a page at a time.

**Path parameters**

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | string | Yes | The campaign ID. |

**Query parameters**

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `pageSize` | integer | No | How many responses to read for one page, from 1 to 25. Send it on every request. |
| `cursor` | string | No | The `continueCursor` from the previous page. |
| `includeTest` | string | No | Send `true` to include responses from test interviews. They are left out otherwise. |

How paging works:

- Send `pageSize`, then follow `continueCursor` until `isDone` is `true`.
- A page can hold fewer responses than `pageSize`, or none, before the last page. Responses hidden by moderation and test responses are left out after the page is read.
- Without `pageSize`, the route returns the whole campaign only if it can read every response in one page. Otherwise it returns 413.
- A page is limited to 6 MiB of data. If a page is larger, the route returns 413. Ask for a smaller `pageSize`.

**Response:** `200 OK`

## Export one response

```text
GET /api/cli/v1/campaigns/{id}/responses/{responseId}/export
```

**Authorization:** scopes `pointed:read` and `pointed:evidence`. Any credential.

Returns one response as a [bundle](#the-response-bundle), with download addresses for its recordings.

**Path parameters**

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | string | Yes | The campaign ID. |
| `responseId` | string | Yes | The response ID. It is `response._id` in a bundle. |
