---
title: Story templates
description: Create reusable interview templates, enroll accounts in them and read each template's roster of interviews.
---

A story template is a reusable interview brief: a goal, an opening question and the kind of interview. Enrolling an account in a template creates that account's campaign and prepares an interview link for each selected contact. Enrolling does not send email.

| Field | Type | Description |
| --- | --- | --- |
| `_id` | string | The template ID. |
| `title` | string | The template's name in your workspace. |
| `customerFacingName` | string | The interview name participants see. Left out when not set. |
| `customerFacingTopic` | string | The topic named in the invitation email. Left out when not set. |
| `role` | string | The kind of person the template is for. |
| `goal` | string | What you want to learn. |
| `description` | string | A description. Left out when not set. |
| `initialQuestion`, `openingQuestion` | string | The opening question. Both fields hold the same value. |
| `maxRounds` | number | The number of interview rounds. |
| `followUpCount` | number | `maxRounds` minus one. |
| `interviewChannel` | string | How participants can take the interview. See [Create a template](#create-a-template). Left out when not set. |
| `status` | string | `active` for a template you can use. |
| `stats` | object | Counts across the template: enrolled accounts, contacts, interviews, responses, completed, prepared, sent and test interviews. |
| `accounts[]` | array | One entry for each enrolled account, with its counts, its `campaignId`, a `status` and `autoIncludeNewContacts`. |
| `contacts[]` | array | The roster: one entry for each interview link. |

Fields of a roster entry that an integration is likely to use:

| Field | Type | Description |
| --- | --- | --- |
| `_id` | string | The invite ID. Use it with the [invite routes](/docs/api/invites). |
| `campaignId`, `accountId`, `contactId` | string | The campaign, account and contact the link belongs to. |
| `recipientName`, `recipientEmail` | string | The person the link was issued to. |
| `status` | string | The state of the link, such as `pending`, `sent`, `opened`, `started` or `completed`. |
| `reviewStatus` | string | The state shown in the Pointed app. It follows the response once one exists. `draft` means the link cannot be shared yet. |
| `responseId` | string or null | The response ID, once the contact has started. Use it with [Export one response](/docs/api/campaigns#export-one-response). |
| `surveyUrl` | string | The interview link. Present only while the link can be shared. |
| `isExpired` | boolean | `true` once the link has passed its expiry. |
| `sentAt`, `lastSentAt`, `lastReminderAt` | number or null | Email times in milliseconds. |
| `inviteType` | string | `campaign` for a real link. `test` for a test link. |

A template can carry other fields that this reference does not list.

## Create a template

```text
POST /api/cli/v1/story-templates
```

**Authorization:** scopes `pointed:read` and `pointed:write`. A user-backed credential with the admin or member role.

**Body parameters**

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `title` | string | Yes, unless `starter` is sent | The template's name in your workspace. |
| `goal` | string | Yes, unless `starter` is sent | What you want to learn. |
| `starter` | string | No | The `id` of a [starter](#list-starters). It fills `title`, `goal` and `interviewLength`. A field you also send wins over the starter. |
| `role` | string | No | The kind of person the template is for. The default is `Account stakeholder`. |
| `customerFacingName` | string | No | The interview name participants see. |
| `customerFacingTopic` | string | No | The topic named in the invitation email. Up to 140 characters. |
| `productName` | string | No | The product the interview is about. |
| `description` | string | No | A description. |
| `initialQuestion` | string | No | The opening question. If you leave it out, Pointed chooses one. |
| `maxRounds` | number | No | The number of interview rounds. The default is 4. |
| `interviewChannel` | string | No | How participants can take the interview. One of the values below. |
| `interviewLength` | string | No | `quick`, `standard` or `deep`. |

Values of `interviewChannel`:

| Value | Meaning |
| --- | --- |
| `phone` | A phone call. |
| `browser` | In the browser. The participant chooses whether to use the camera. |
| `browser_audio` | In the browser, voice only. |
| `browser_video` | In the browser, on camera. |
| `participant_choice` | The participant chooses phone or browser. |

**Response:** `201 Created`. `data` is the stored template, without `stats`, `accounts` or `contacts`.

```json
{
  "data": {
    "_id": "ks91t4w7y2z5b8d3g6j0m1n4pq",
    "_creationTime": 1794736800000,
    "orgId": "kd7w2m4x8q1v6n3s9t5y0z2b7c",
    "title": "Customer stories",
    "role": "Account stakeholder",
    "goal": "Capture the before-and-after story behind the results customers have seen.",
    "initialQuestion": "What changed after you adopted the product?",
    "maxRounds": 4,
    "interviewChannel": "browser",
    "status": "active",
    "createdBy": "kn83p5r2u7h4b1d6g9j0m3c8fa",
    "createdAt": 1794736800000
  },
  "meta": {
    "requestId": "3f6c1e0a-8b7d-4c2e-9a41-5d0e7b9c2f18"
  }
}
```

**Errors**

| Status | When |
| --- | --- |
| 400 | The body is not a JSON object, or `starter` is not a known starter ID. |
| 400 | `title` or `goal` is missing, `role` is empty, or a field has the wrong type. |
| 400 | `customerFacingTopic` is longer than 140 characters, or `interviewChannel` or `interviewLength` is not an allowed value. |
| 403 | The credential may not write. See [authentication errors](/docs/api/authentication#authentication-errors). |
| 500 | The request could not be completed. |

**Example**

```bash
curl -X POST https://app.usepointed.ai/api/cli/v1/story-templates \
  -H "Authorization: Bearer $POINTED_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Customer stories",
    "goal": "Capture the before-and-after story behind the results customers have seen.",
    "initialQuestion": "What changed after you adopted the product?",
    "interviewChannel": "browser"
  }'
```

```text
PATCH /api/cli/v1/story-templates/{id}
```

**Authorization:** scopes `pointed:read` and `pointed:write`. A user-backed credential with the admin or member role.

Send only the fields you want to change. To change the interview channel, use [interview settings](/docs/api/interview-settings).

**Path parameters**

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | string | Yes | The template ID. |

**Body parameters**

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `title` | string | No | The template's name in your workspace. |
| `customerFacingName` | string | No | The interview name participants see. |
| `customerFacingTopic` | string | No | The topic named in the invitation email. Up to 140 characters. |
| `role` | string | No | The kind of person the template is for. |
| `goal` | string | No | What you want to learn. |
| `description` | string | No | A description. |
| `initialQuestion` | string | No | The opening question. See the 409 error below. |

```json

  "data": {
    "_id": "ks91t4w7y2z5b8d3g6j0m1n4pq",
    "_creationTime": 1794736800000,
    "orgId": "kd7w2m4x8q1v6n3s9t5y0z2b7c",

    "interviewChannel": "browser",
    "status": "active",
    "createdBy": "kn83p5r2u7h4b1d6g9j0m3c8fa",
    "createdAt": 1794736800000
  },
  "meta": {
    "requestId": "3f6c1e0a-8b7d-4c2e-9a41-5d0e7b9c2f18"

```

**Errors**

| Status | `meta.code` | When |
| --- | --- | --- |
| 400 | none | The body is not a JSON object, a field has the wrong type, or `customerFacingTopic` is longer than 140 characters. |
| 403 | none | The credential may not write. See [authentication errors](/docs/api/authentication#authentication-errors). |

curl -X PATCH https://app.usepointed.ai/api/cli/v1/story-templates/ks91t4w7y2z5b8d3g6j0m1n4pq \

## Enroll accounts

```text
POST /api/cli/v1/story-templates/{id}/enroll
```

**Authorization:** scopes `pointed:read` and `pointed:write`. A user-backed credential with the admin or member role.

Enrolls one or more accounts in the template. For each account, Pointed creates the account's campaign if it has none for this template, and prepares an interview link for each selected contact. No email is sent.

**Path parameters**

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | string | Yes | The template ID. |

**Body parameters**

Send one selection at the top level of the body, or several in `selections`.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `accountId` | string | Yes | The account to enroll. |
| `contactIds` | array of strings | No | The contacts to prepare links for, by ID. |
| `contactEmails` | array of strings | No | The contacts to prepare links for, by email. Case is ignored. |
| `autoIncludeNewContacts` | boolean | No | If `true`, a contact added to the account later gets a link in this template automatically. If you leave it out, a newly enrolled account uses the template's default and an enrolled account keeps its setting. |
| `selections` | array | No | A list of selections, each with the four fields above. Use it to enroll several accounts in one request. It cannot be empty. |

Rules for choosing contacts:

- Send `contactIds` or `contactEmails`, not both.
- Send neither to select every contact on the account.
- Send an empty `contactIds` array to enroll the account without preparing any link.

The request is all or nothing. If one selection is refused, nothing is saved.

**Response:** `200 OK`

```json
{
  "data": {
    "accountsProcessed": 1,
    "invitesPrepared": 1,
    "invitesAlreadyPrepared": 0,
    "invitesWithoutLinks": 0
  },
  "meta": {
    "requestId": "3f6c1e0a-8b7d-4c2e-9a41-5d0e7b9c2f18"
  }
}
```

| Field | Type | Description |
| --- | --- | --- |
| `accountsProcessed` | number | How many selections were handled. |
| `invitesPrepared` | number | New links that can be shared. |
| `invitesAlreadyPrepared` | number | Contacts that already had a link that can be shared. |
| `invitesWithoutLinks` | number | Contacts enrolled without a link that can be shared, for example because the interview has no voice channel set up. |

Enrolling does not return the links. Get them from [Create interview links](/docs/api/campaigns#create-interview-links) with the account's campaign ID, or from `contacts[].surveyUrl` in [Get a template](#get-a-template).

**Errors**

| Status | When |
| --- | --- |
| 400 | The body is not a JSON object, `selections` is not a non-empty array, a selection has no `accountId`, both `contactIds` and `contactEmails` were sent, or a field has the wrong type. |
| 400 | A contact ID does not belong to the selected account, or a contact email is not on the selected account. |
| 403 | The credential may not write. See [authentication errors](/docs/api/authentication#authentication-errors). |
| 500 | The template or an account was not found, or an ID is malformed. |

**Example**

```bash
curl -X POST https://app.usepointed.ai/api/cli/v1/story-templates/ks91t4w7y2z5b8d3g6j0m1n4pq/enroll \
  -H "Authorization: Bearer $POINTED_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "accountId": "j57a1m6c3x9z2q8w4e7r5t0y1u",
    "contactIds": ["k17c9p4e2r8u5h3b6d1g0j7m9n"],
    "autoIncludeNewContacts": true
  }'
```

## Import campaigns without a template

```text
POST /api/cli/v1/story-templates/import-legacy
```

**Authorization:** scopes `pointed:read` and `pointed:write`. A user-backed credential with the admin or member role.

Creates one story template for each campaign counted by the [summary](#summarize-campaigns-without-a-template). The template takes the campaign's title, opening question and number of rounds, and uses the campaign's context as its goal. The campaign is attached to the new template and its account is enrolled. No email is sent.

The route takes no body.

**Response:** `200 OK`

```json
{
  "data": {
    "importedTemplates": 1,
    "linkedCampaigns": 1,
    "createdEnrollments": 1
  },
  "meta": {
    "requestId": "3f6c1e0a-8b7d-4c2e-9a41-5d0e7b9c2f18"
  }
}
```

| Field | Type | Description |
| --- | --- | --- |
| `importedTemplates` | number | How many templates were created. |
| `linkedCampaigns` | number | How many campaigns were attached to a template. |
| `createdEnrollments` | number | How many account enrollments were created. |

**Errors**

| Status | When |
| --- | --- |
| 403 | The credential may not write. See [authentication errors](/docs/api/authentication#authentication-errors). |
| 500 | The request could not be completed. |

**Example**

```bash
curl -X POST https://app.usepointed.ai/api/cli/v1/story-templates/import-legacy \
  -H "Authorization: Bearer $POINTED_API_KEY"
```
