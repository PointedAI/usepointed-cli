## 0.5.0 — Unreleased source

- CSV/TSV account and contact imports with dry runs, company matching, phone fields, and optional template enrollment.
- Account domains, revenue aliases, renewal dates, custom fields, clearing and interviewer context. Context failures retain the saved account and exit nonzero.
- Contact phone create/update/clear and JSON batch support.
- Interview-template starters, product, channel and length options; whole-account enrollment with mutually exclusive scopes.
- Opaque IDs, strict numeric parsing, empty-selector guards and complete failure output are preserved. Partial import or enrollment failures print the full JSON result and exit with status 1.

These features have not been published to npm. Use [Run from source](/docs/installation#run-from-source); npm latest remains 0.4.0.

## 0.4.0 — November 6, 2026

Adds workspace interview settings commands for reusable demos and interview templates, effective ElevenLabs provider tuning reads, and founder browser/phone settings for platform administrators. JSON exports retain the saved revision; conflicting writes preserve the current revision in machine-readable output and never retry automatically. Configuration saves do not start calls or recordings.

[npm package](https://www.npmjs.com/package/@pointed/cli/v/0.4.0) · [GitHub release](https://github.com/PointedAI/usepointed-cli/releases/tag/v0.4.0)

## 0.2.0 — October 4, 2026

The first public npm release of [`@pointed/cli`](https://www.npmjs.com/package/@pointed/cli), including the earlier feature work and the October security and reliability fixes.

### Customer collection workflows

- Accounts, contacts, campaigns, survey links, and story template enrollment
- Account and campaign updates
- Invitation preview, test, send, reminder, and delivery issue clearing
- Smart intake preview and commit for account and contact imports
- Response data, transcript, media, summary, and manifest exports
- Browser OAuth login, refresh, logout, and existing API key support

### October fixes

- Private local credential/configuration files and export directories, with ownership and permission checks
- OAuth callback validation and terminal output escaping
- Opaque identifier handling and rejection of explicitly empty contact selectors
- Strict numeric validation and removal of unsupported contact department fields
- Complete batch results and failure exit status for partial operations
- Bounded campaign export pagination and manifests that report final download outcomes

Source changes: [local storage and OAuth hardening](https://github.com/PointedAI/usepointed-cli/pull/3) and [request targeting and operation reporting](https://github.com/PointedAI/usepointed-cli/pull/4).

## Development history before npm publication

### May 23, 2026

The source version moved to 0.2.0 with account/campaign updates, smart intake, and inline spinner feedback. These changes were published to npm as part of the October 4 release.

### April 26, 2026

Initial 0.1.0 source preparation included the core collection commands, story templates, invitation email, response exports, and authentication. Version 0.1.0 was not published to the public npm registry.
