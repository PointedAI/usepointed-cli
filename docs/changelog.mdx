## 0.2.0

Feature parity release.

- `accounts update` command for editing account name, industry, contract value, and notes
- `campaigns update` command for editing title, description, context, initial question, and max rounds
- `smart-intake preview` and `smart-intake commit` commands for AI-powered bulk account and contact import
- Inline spinner feedback during long-running operations

## 0.1.0

Initial public CLI package preparation.

- Accounts, contacts, campaigns, and link generation
- Story template creation, enrollment, account state, and legacy import
- Invite email preview, test, send, remind, and delivery issue clearing
- Response listing and export download
- OAuth and API key authentication
