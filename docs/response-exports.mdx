## Review an interview in Results

Open **Results** and search a transcript, or filter the interviews by template or account. Choose **View** to read one interview’s summary, quotes and transcript. Select a quote to jump to its question. For a continuous recording, open the full interview page to use the recording timeline.

Use **Share** to copy a link for someone with access to the workspace. **Download transcript** saves a plain-text copy. For the full export, including available media and the manifest, use the CLI commands below.

## Review patterns across interviews

In **Results** or **Analytics**, choose **AI insights** to open the workspace agent. Pick a suggested question or ask your own about quotes, themes, or feedback across interviews. The agent asks for approval before it makes workspace changes.

**Analytics** shows emailed invitations and the distinct accounts and contacts reached, completed customer interviews, the overall sentiment with its positive, neutral, and negative counts, and the average duration of completed interviews with recorded timing. Test interviews are excluded. A missing duration is left out of the average.

## List responses

```bash
pointed responses list --campaign-id <campaignId>
```

## Download one response

```bash
pointed responses download \
  --campaign-id <campaignId> \
  --response-id <responseId> \
  --output-dir ./pointed-export
```

## Download all responses for a campaign

```bash
pointed responses download \
  --campaign-id <campaignId> \
  --output-dir ./pointed-export
```

## Export shape

Single response:

```text
<output-dir>/response-<contact-slug>-<date>-<response-id>-<unique-suffix>/
  response.json
  round-1-transcript.txt
  round-2-transcript.txt
  response-<contact-slug>-<date>-round-1.mp4
  response-<contact-slug>-<date>-round-2.mp4
  ai-summary.txt
  insights.json
  manifest.json
```

Full campaign:

```text
<output-dir>/campaign-<title-slug>-<unique-suffix>/
  campaign.json
  manifest.json
  response-<contact-slug>-<date>-<response-id>-<unique-suffix>/
    response.json
    round-*-transcript.txt
    response-<contact-slug>-<date>-round-*.mp4
    ai-summary.txt
    insights.json
    manifest.json
```

Every run creates a new private export directory and preserves previous exports.

In `response.json`, `response.sentiment` is the interview’s displayed label (`positive`, `neutral` or `negative`). New summaries can supply the label directly. Older scored interviews derive it from `response.sentimentScore`, which remains on its original −1 to +1 scale. An interview without either value exports a null label. Files downloaded before this field was introduced can omit it.

Each response's `manifest.json` includes final `processingWarnings` and a `videoDownloads` entry for each asset, with its filename, download status, and any failure reason. These reflect the download attempt, including network and file errors, rather than only the API's initial processing state.

Campaign exports also write a top-level `manifest.json`. It records every requested response as `exported`, `partial`, or `failed`, with its output directory when available and any warnings. `exportedResponses` counts fully exported responses; `failedResponses` includes partial exports.

The command exits with status 1 when a response cannot be exported or a ready video fails to download. Successfully written files are preserved, and campaign downloads continue attempting the remaining responses. Media that is still preparing or unavailable is recorded as a warning and does not alone make the command fail.
