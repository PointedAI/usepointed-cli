## Connect to your Pointed workspace

The Pointed workspace MCP server uses Streamable HTTP at `https://app.usepointed.ai/mcp`. Access is available to enabled workspaces through an approved OAuth client.

1. Open the Pointed connection supplied for your workspace. In a supported custom client, use the server URL above and select OAuth. If you need a connection for your client or workspace, [contact Pointed](https://usepointed.ai/contact?reason=general).
2. Sign in with the Pointed account that belongs to the workspace you want to use. If you just received a Pointed invitation, accept it using the email address it was sent to, then return to the connection.
3. Review the requested permissions. Ask your assistant **“Which Pointed workspace am I connected to?”** The `get_workspace` tool returns the workspace name and available capabilities. Check the name before asking it to work with customer data.

With read access you can find accounts, interviews and response progress. Preparing an interview draft requires write permission. Reading interview excerpts or cited insights requires evidence access. Pointed checks your current workspace role when you use a tool. Saving a draft leaves you in control of sending invitations.

A workspace admin can also ask the assistant to set up a [webhook](/docs/webhooks), so their own system hears when an interview finishes. The assistant can save an endpoint, read its signing secret once, send test events and read the delivery log. An endpoint saved this way sends nothing about real interviews until an admin turns it on in Pointed, under **Settings → Webhooks**, where the full address is shown.

If your client asks you to reconnect after a sign-in change, reconnect the Pointed account and check the workspace name again. Integration developers can discover the current authorization server and supported scopes from [Pointed’s resource metadata](https://app.usepointed.ai/.well-known/oauth-protected-resource/mcp).

## Read the documentation with an assistant

The public documentation has a [page index](https://docs.usepointed.ai/llms.txt) and [complete text](https://docs.usepointed.ai/llms-full.txt) for tools that read Markdown.

Mintlify also hosts a documentation MCP server:

```text
https://docs.usepointed.ai/mcp
```

Use that URL in an MCP client that supports remote HTTP servers. It does not require your Pointed credentials.

The documentation server searches and reads the published CLI guides. It also offers a tool for submitting documentation feedback. It has no access to your private Pointed workspace, customer contacts, interviews, or response exports, and cannot send invitations or change records.

## Use the CLI from an agent

An agent with terminal access can use the installed CLI after you complete [authentication](/docs/authentication). Start with `pointed auth whoami`, `pointed --help`, and read commands such as `pointed accounts list` to confirm the intended account and operation.

Review customer records and recipient selections before a write. Creating contacts or campaigns, enrolling accounts, and generating links change workspace data. Sending or reminding an invitation contacts a customer and should follow your explicit approval.

For batch operations, inspect the JSON output and exit status. A nonzero exit can include successful items alongside failures; [response export manifests](/docs/response-exports) preserve each outcome. Check what succeeded before retrying.
